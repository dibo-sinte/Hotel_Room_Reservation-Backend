## 📌 Project Overview

A backend system for managing hotel room reservations.  
It allows users to browse available rooms, make bookings, cancel reservations, and request refunds according to hotel policies.

Supports:
- 🏆 VIP and Standard room types  
- 👤 Optional user accounts  
- 📧 Email confirmations  
- 📄 PDF receipts  

---

## 🧠 Description

This project is built using **PHP** and **MySQL**, and communicates with the frontend using **JSON APIs**.

It handles:
- Booking logic  
- Payment processing  
- Reservation management  
- Confirmation services  

---

## 🚀 Features

- ✅ Book available rooms  
- 💳 Payment integration  
- 🔄 Cancellation & refund system  
- 📧 Email confirmations  
- 📄 PDF receipt generation  
- 👤 Optional account system (loyalty & discounts)

## ⚙️ Setup Guide

Follow these steps to run the project locally:

### 🔧 Prerequisites

Make sure you have installed:
- PHP  
- Composer  

---

### 📥 Clone Repository

```bash
git clone https://github.com/five-code-nerds/Hotel_Room_Reservation-Backend.git
cd Hotel_Room_Reservation-Backend
```

---

### 📦 Install Dependencies

```bash
composer init
composer install
```

---

### ▶️ Run Local Server

```bash
php -S localhost:3000 -t public
```

---
